**E-Commerce Website**

A full-stack E-Commerce web application built by me using modern web technologies.
The project allows users to browse products, create accounts, login securely, add items to cart, stripe payment gateway and place orders.

**Features**
User Authentication (Login & Signup)
Product Listing Page
Add to Cart Functionality
Responsive UI Design
Secure Backend API
MongoDB Database Integration
REST API Support


**payment gateway**
Stripe payment API
